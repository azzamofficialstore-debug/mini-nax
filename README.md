# Mini Nax, AI Social Media Starter Kit

**Bonus pendamping SOP Social Media Playbook dari Insightory by Nakama.**

Mini Nax adalah versi ringan dari Nax (AI Social Media & Content System Developer profesional). Dirancang sebagai pintu masuk yang fungsional, supaya kamu sebagai pembaca SOP Social Media Playbook bisa langsung dapet output yang bisa dipakai untuk 3 kebutuhan operasional dasar.

---

## Apa yang Bisa Mini Nax Lakukan

### 1. Team Structure Recommendation

Kasih konteks singkat (industri, tujuan socmed, jumlah orang yang bisa di-hire, channel utama). Mini Nax bantu pilih model komposisi tim yang paling cocok untuk tim 2-6 orang. Output: rekomendasi role + brief description per posisi + adjustment industri + **Risks & Mitigations** spesifik untuk model yang dipick + **30-Day Quick Start** (4 action minggu 1-4 untuk membentuk tim baru).

### 2. Workflow Outline

Kasih konteks tim dan kapasitas konten per bulan. Mini Nax kasih workflow garis besar untuk content production (9 step: brief sampai analisis), plus estimasi waktu per step yang sudah disesuaikan dengan ukuran tim kamu, plus **Weekly Rhythm Template** (gambaran kasar 1 minggu kerja Senin-Jumat untuk ukuran tim kamu), plus **3 Red Flags Workflow** yang harus dipantau supaya operasional tidak kolaps.

### 3. Maturity Self-Check

Jawab 6 pertanyaan self-scoring, Mini Nax mapping kondisi sistem social media kamu ke Level 1-5 (Ad Hoc, Basic, Structured, Optimized, Scalable). Kamu juga dapet 2-3 dimensi paling lemah, 1 quick-win action minggu ini, dan pointer ke bab playbook prioritas.

### Bonus: Consultative Upsell

Setelah deliver setiap capability, Mini Nax akan bridging ke Nax full secara konsultatif. Mini Nax akan menanyakan pain point spesifik kamu, kasih insight ringan, dan kalau relevan, arahkan ke Capability Nax full yang handle area itu lebih dalam. Bukan hard-sell, kamu bisa skip kalau cukup di output capability aja.

## Apa yang Mini Nax TIDAK Lakukan

Mini Nax dirancang dengan scope sengaja sempit. Untuk kebutuhan di bawah ini, gunakan **Nax full** (AI Skill profesional terpisah dari Insightory by Nakama):

- Custom SOP detail per channel (organik, ads, KOL, live shopping)
- Custom KPI framework per role dengan target spesifik
- Budget planning lengkap (gaji + tools + production cost)
- Onboarding system lengkap dengan timeline + materi per role
- Assessment kompetensi tim (test kemampuan individu)
- Behavioral assessment / performance review
- Hiring blueprint phasing 6-12 bulan
- Custom team design dengan reasoning detail per role
- Generate file deliverable DOCX/XLSX/PDF

Mini Nax akan secara aktif redirect ke Nax full atau ke bab playbook spesifik kalau kebutuhan kamu di luar 3 capability di atas.

## Cara Install

### Untuk Claude Pro / Team / Enterprise

1. Download semua file Mini Nax (folder ini).
2. Buka Claude di browser, masuk ke Project (kalau ada) atau langsung New Chat.
3. Upload semua file di folder ini ke Claude:
 - `SKILL.md`
 - `SYSTEM-PROMPT.md`
 - `standards/humanize-writing-guide.md`
 - `references/team-composition-mini.md`
 - `references/workflow-mini.md`
 - `references/maturity-self-check.md`
 - `references/upsell-bridging-mini.md`
4. Mulai chat dengan: "Halo Mini Nax, saya pembaca SOP Social Media Playbook." atau langsung sebut kebutuhan kamu.

### Untuk ChatGPT atau AI lain (alternatif)

Mini Nax dirancang untuk Claude, tapi bisa dipakai di AI lain (ChatGPT, Gemini, dll) dengan cara:

1. Copy isi file `SYSTEM-PROMPT.md` jadi system prompt / custom instruction.
2. Tambahkan isi file `SKILL.md` sebagai context.
3. Untuk file references, copy-paste isinya ke chat saat dibutuhkan.

Catatan: pengalaman terbaik tetap di Claude karena Mini Nax dirancang dengan struktur AI Skill native.

## Tips Pakai Mini Nax

- **Mulai dari menu**, di interaksi pertama, Mini Nax akan kasih 3 pilihan capability. Pilih satu, jangan tanya 3 sekaligus.
- **Konteks ringkas itu cukup**, Mini Nax tidak perlu brand profile lengkap, cukup 3-4 hal singkat sesuai pertanyaannya.
- **Output langsung di chat**, Mini Nax tidak generate file. Copy-paste manual ke Notion atau Google Docs kamu.
- **Kalau Mini Nax bilang "redirect ke Nax full"**, itu sinyal bahwa kebutuhan kamu sudah di luar scope Mini Nax. Pertimbangkan upgrade ke Nax full untuk hasil yang lebih dalam.
